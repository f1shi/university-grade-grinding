# 🎓 University Grade Grinding

Трекер баллов для группы: посещения, баллы за семинары и задания с файлами.

**Сайт:** https://f1shi.github.io/university-grade-grinding/

## Как считаются баллы

По каждому предмету максимум **60 баллов**:

- **20 — посещение лекций** (у иностранного языка — практик). По умолчанию всё посещено.
  Засчитывается не больше максимума посещений (7, у иностранного — 14). Если занятий в семестре больше
  (у матана 14 лекций), лишние можно прогулять без потерь — сайт показывает, сколько ещё можно.
  Каждый прогул сверх этого вычитает `20 / максимум` (≈ 2,9 балла при 7, ≈ 1,4 при 14).
- **40 — работа на семинарах.** Добавляйте полученные баллы вручную; больше 40 не засчитывается.

## Где хранятся данные

Сервера нет — это статический сайт на GitHub Pages. Поэтому:

| Что | Где |
|---|---|
| Ваши прогулы, баллы, свои задания | `localStorage` вашего браузера (у каждого своё) |
| Файлы к своим заданиям | IndexedDB браузера (только на этом устройстве) |
| Расписание пар | [`src/data/timetable.ts`](src/data/timetable.ts) |
| Общие задания для группы | [`public/data/shared.json`](public/data/shared.json) в репозитории |
| Общие файлы к заданиям | папка [`public/files/<предмет>/`](public/files) |

На странице «Обзор» есть кнопки для резервной копии отметок и баллов в JSON.

## Как добавить общее задание для всей группы

1. Положите файлы в `public/files/<id предмета>/`, например `public/files/web/lab1.pdf`.
2. Добавьте задание в `tasks` в `public/data/shared.json`:
   ```json
   {
     "id": "web-lab1",
     "subjectId": "web",
     "title": "ЛР 1",
     "description": "Что нужно сделать",
     "deadline": "2026-11-01",
     "files": [{ "name": "lab1.pdf", "path": "files/web/lab1.pdf" }]
   }
   ```
   Удобно: создайте задание на сайте и нажмите «Скопировать JSON для группы».
3. Закоммитьте в `main` — сайт пересоберётся сам.

## Расписание

Две чередующиеся недели (нечётная — как 14–20 сентября, чётная — как 21–27 сентября) описаны в
[`src/data/timetable.ts`](src/data/timetable.ts). Из них генерируются все пары с 3-й по 16-ю неделю
(14 сентября — 20 декабря). Если что-то поменялось — правьте список `SLOTS`.

ID предметов: `asd`, `db`, `english`, `isb`, `matan`, `law`, `project`, `ai`, `tip`, `web`
(список — в [`src/data/subjects.ts`](src/data/subjects.ts)).

## Разработка

```bash
npm install
npm run dev
```

Стек: React 18 + TypeScript + Vite. Node нужен только для сборки (локально и в GitHub Actions), на сайте его нет. Деплой — GitHub Actions
([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)) при каждом пуше в `main`.
